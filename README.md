# KINGS Café Ad Gallery

A static, single-page gallery with 42 finished concepts and 75 image files, grouped into eight dish/menu categories.

## View locally
Open index.html directly, or run python3 -m http.server 8080 in this folder. No build, dependencies, API keys or account required.

## GitHub Pages
Upload index.html, .nojekyll and the assets folder together into the repository root. In Settings > Pages, select Deploy from a branch, choose the intended branch and / (root). Relative asset URLs also work on repository project pages.

## Contents
Includes Escape the Usual Breakfast ads 01–30, the latest 11 brand concepts with their 33 additional format exports, and the Benny Bagel swipe. Superseded bright drafts and replaced versions are excluded. Multi-dish creatives appear in Menu & catch-ups.

## Reviewing
Three columns on desktop, two on tablet and one on mobile. Filter by dish or collection. Open full-size previews or download the currently selected format. Escape closes previews. Existing copy is available below the images.

## Assets
KINGS-owned campaign material for team review. Keep the assets directory with index.html.
